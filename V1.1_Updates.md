# CyberGuard AI - Prototype Roadmap

This document outlines the strategic ML roadmap for CyberGuard AI. All V1.1 security, anti-tampering, and architectural performance features have been fully implemented in the Android codebase.

---

## 1. AI Pipeline Fine-Tuning & Accuracy Optimization (Pending Offline ML Task)
With 3 months available, the ML engineering team will transcend off-the-shelf models and produce highly tailored inference files to maximize scam detection precision.

*   **The NLP Intent Model (`minilm_int8.ort`):** We will fine-tune a HuggingFace Sentence Transformer (e.g., `all-MiniLM-L6-v2`) on real-world Indian scam transcripts (containing phrases like "Digital Arrest", "CBI", "OTP"). It will be dynamically quantized to INT8 and exported to `.ort` format using `onnxruntime.tools.convert_onnx_models_to_ort`.
*   **The ASR / Speech-To-Text Model (`model.int8.onnx`):** We will fine-tune an NVIDIA NeMo Fast-Conformer CTC model (or Sherpa-compatible transducer) to understand heavy regional accents and hinglish vocabulary ("Aadhar card", "Pan card"). INT8 Quantization is mandatory to prevent Out-Of-Memory (OOM) crashes on low-end devices.
*   **Integration Pipeline:** Once fine-tuned and exported with these exact names, the models will be placed in the `raw_models_backup/` directory. The automated `encrypt_models.py` script will encrypt them via AES-256 and deploy them directly into the Android `assets/` folder, requiring zero changes to the Kotlin codebase.
