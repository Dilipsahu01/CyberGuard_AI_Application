# CyberGuard AI - Project Updates & Roadmap

This document summarizes the latest implementation milestones and the strategic ML roadmap for CyberGuard AI.

---

## 🚀 Security Hardening Milestone (Completed July 2026)

We have successfully completed a major security and architectural hardening phase to bring the application to a production-ready, compliant state.

### 🛡️ Compliance & Privacy (DPDP Act)
- **PII Scrubbing:** Implemented `TranscriptScrubber.kt` which utilizes localized Named Entity Recognition (NER) proxies to mask OTPs, names, and account IDs in call transcripts.
- **Binary-Only Telemetry:** Removed all insecure JSON telemetry paths. The app now exclusively uses an 82-bit compressed binary format for Swarm intelligence.
- **Right to be Forgotten:** Added a "Purge All My Data" feature in settings that triggers a local database wipe and a server-side cascade delete request.

### 🗄️ Storage Security
- **SQLCipher Integration:** All local Room databases are now encrypted at rest using 256-bit AES.
- **Hardware-Linked Passphrases:** Database encryption keys are randomly generated and locked within the Android Hardware Keystore (TEE).

### 🌐 Network & Secrets
- **TLS Certificate Pinning:** Hardened the network layer to prevent MITM attacks.
- **Dynamic Key Derivation:** Refactored JNI `secrets.cpp` to use hardware-unique salts for runtime key generation.
- **IP Protection:** Implemented an immediate disk cache purge for decrypted AI model weights.
